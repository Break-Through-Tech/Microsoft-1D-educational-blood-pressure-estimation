# Engineering Principles

- **KISS** — Prefer the simplest correct solution.
- **YAGNI** — Avoid speculative features and abstractions.
- **DRY** — Reuse established logic; avoid duplication.
- **SRP** — Keep functions and modules focused.
- **TEST** — Verify behavior with relevant tests.
- **CLEAN** — Remove obsolete code only after verifying it is unused.
- **SCOPE** — Make focused changes; avoid unrelated refactors.
