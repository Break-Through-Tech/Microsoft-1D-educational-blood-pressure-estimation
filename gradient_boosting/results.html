Gradient boosting: what I tried and learned

I use five seconds of PPG to estimate SBP (the upper BP number) and DBP (the lower number). ABP provides the training labels; prediction itself needs only PPG.

How to read the scores: MAE is the average absolute error in mmHg. Lower is better. The main tables give each recording equal weight, so long recordings do not dominate.

1. Do extra pulse features help?

What I tried

Compared six basic signal summaries with 17 features that also describe pulse timing, width, area and slopes. Both use the same training/validation windows and boosting settings.

Input featuresValidation SBP MAEValidation DBP MAE
6 summary features17.198.43
17 features (summary + pulse shape)14.867.48

What I learned

The pulse-shape features lowered both errors in this comparison. I kept all 17 features.

2. Which settings worked best?

What I tried

Tested learning rates 0.05 and 0.1, with 15 or 31 leaves. Each target was selected using validation MAE, with every recording weighted equally. The test set was not used to choose settings.

What I learned

The configured model uses learning rate 0.1 and 31 leaves, with 100 iterations. Both validation targets favored 0.1 and 31 leaves. Ridge uses alpha 100.

3. Does learning beat a simple guess?

What I tried

Compared boosting with a linear Ridge model and two models that always return a training-data constant. Models were trained on training data, saved, and then evaluated on the reserved test recordings.

Scored 78,667 of 78,946 test windows from 1,793 recordings. Predictions also exist for usable PPG windows without valid ABP labels; those windows cannot receive an error score.

What I learned

Boosting has the lowest overall errors in this comparison. Check the pressure ranges below: lower overall MAE does not guarantee reliable high-pressure predictions.

Limits to remember

  • Recordings are separated, but different recordings may come from the same person.
  • Reference labels can contain artifacts. Low/high-pressure errors need separate checks.
  • These results do not establish new-patient or new-device performance. EDA preceded splitting; validation informed development.
  • The test has now been evaluated. Later model changes are new exploratory experiments.
